# Code of Conduct

This project should be a useful, respectful place to collaborate.

## Expected Behavior

- Be kind and direct.
- Assume good intent, but name issues clearly.
- Give feedback about the work, not the person.
- Respect different experience levels.
- Keep discussions relevant to the project.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Sharing private data without permission.
- Spam, trolling, or repeated off-topic comments.

## Enforcement

Maintainers may remove comments, close issues, block users, or take other reasonable action to keep the project healthy.

If you need to report a concern, contact the maintainer privately.
